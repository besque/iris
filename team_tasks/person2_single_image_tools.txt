PERSON 2: SINGLE-IMAGE SPECIALIST (VQA + GROUNDING/CAPTION)
============================================================
Read team_tasks/README.txt first for the big picture.

CONTEXT: WHY YOUR ROLE EXISTS
-----------------------------
When a user uploads ONE satellite image and asks "how many buildings are
near the river?" or "highlight the water body", YOUR model answers. The
problem statement makes single-image VQA mandatory, plus ONE more task:
captioning (describe the scene) OR grounding (draw a box around the thing
the user asked about). You deliver both tools.

Why we cannot just use ChatGPT-style models: satellite images are top-down,
weird resolutions, strange bands. Generic models are bad at them AND the
rules say a generic model without remote-sensing adaptation is disqualified.
So you use a model already trained on satellite imagery.

THE MODEL: USE GEOCHAT. DO NOT SPEND THE HOUR RE-DECIDING.
----------------------------------------------------------
GeoChat (https://github.com/mbzuai-oryx/GeoChat) is a 7B vision-language
model trained specifically on satellite images. It does ALL THREE of our
tasks in one model: VQA, captioning, AND grounding (it can output boxes).
Weights: https://huggingface.co/MBZUAI/geochat-7B
It counts as "remote-sensing adapted" which the rules demand.
Your 1-hour research budget is only for: confirming you can load it, and
skimming its README for the prompt format (grounding uses a special tag
like [grounding] in the prompt; captioning is just "describe the image").

WHERE TO RUN IT: free Colab (T4 GPU, 16GB) or Kaggle (free 2xT4).
A 7B model fits on a T4 if you load it 4-bit:
  load_in_4bit=True via bitsandbytes (their repo/LLaVA loading code shows how).
The 5070 Ti is Person 4's for fine-tuning; ask before borrowing it.

YOUR TASKS, IN ORDER
--------------------
TASK 1 (MINIMUM): get GeoChat answering ONE question on ONE image.
  a) Colab notebook: clone their repo, install their requirements,
     download weights, load 4-bit.
  b) Feed it any satellite image (grab one from the RSVQA or VRSBench
     dataset, or even a Google Maps screenshot for smoke-testing).
  c) Ask "What is shown in this image?" and get a sane answer.
  This is your make-or-break moment; do it before anything else.
  IF IT WON'T RUN by early afternoon, FALLBACK: Qwen2-VL-2B-Instruct
  (tiny, easy to load, decent on aerial images). It is NOT RS-adapted, but
  Person 4's fine-tune satisfies the adaptation rule, so we survive. Tell
  the group if you fall back.

TASK 2 (MINIMUM): wrap it as our Tool.
  Copy the pattern from backend/tools/mocks.py. Create:
    backend/tools/vqa/geochat_vqa.py   -> class GeoChatVQA(Tool)
    backend/tools/grounding/geochat_grounding.py -> class GeoChatGrounding(Tool)
  Rules:
  - subclass Tool from backend/tools/base.py, do NOT change base.py
  - run(images, query, **params) returns ToolResult:
      text        = the answer string
      spatial     = for grounding: {"type": "bbox", "data": [[x1,y1,x2,y2],...]}
                    (parse GeoChat's box output into plain pixel coords)
      confidence  = GeoChat gives no score, so use a fixed honest value
                    (e.g. 0.7) and put "confidence_source": "fixed" in
                    metadata. Do not fake precision.
      metadata    = {"model": "geochat-7B", "params": <params you used>}
  - the image arrives as an RGB numpy array or a PNG path (Person 4's
    converter guarantees this; until then test with plain PNG files)
  PRACTICAL ISSUE: the model lives on Colab, the app runs on our machine.
  Options: (a) run the whole demo on Colab, (b) expose the Colab model via
  a tunnel and have the Tool call it over HTTP, or (c) borrow the 5070 Ti
  after Person 4's fine-tune finishes and run 4-bit locally.
  (c) is cleanest for demo day; plan for it with Person 4 and Person 1.

TASK 3 (MINIMUM): tiny test script.
  scripts/test_single_image_tools.py: loads 3 sample images, runs one VQA
  question and one grounding query on each, prints results. Person 1 runs
  this before wiring you into the registry.

TASK 4 (BETTER): pick grounding over caption as our "second task" and make
  it pretty. Judges love seeing "highlight the water body" put a box
  exactly on the lake. Test 5-6 grounding phrasings, note which work.
  (GeoChat can also caption, so we can honestly claim all three tasks.)

TASK 5 (BETTER): evaluation numbers.
  Download RSVQA-LR (https://rsvqa.sylvainlobry.com/), run your tool on a
  few hundred test questions, report accuracy in evaluation/results/.
  Any real number beats "we didn't measure".
