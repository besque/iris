PERSON 3: CHANGE ANALYSIS (TWO DATES, SAME PLACE)
==================================================
Read team_tasks/README.txt first for the big picture.

CONTEXT: WHY YOUR ROLE EXISTS
-----------------------------
The single most valuable real-world question in remote sensing is "what
changed?": which villages flooded since last week, how much the city grew,
where forest disappeared. The problem statement calls paired-image reasoning
the PRINCIPAL FOCUS, and change analysis from two dates is mandatory. You
own everything that happens when a user uploads two images of the same
place from different times and asks about the difference.

Queries you must handle (straight from the problem statement):
  "What changed between these two dates, and where did the change occur?"
  "Has the built-up area increased, decreased, or remained unchanged?"
Your answer needs BOTH words ("built-up area grew in the south-east") AND,
ideally, a picture (a change map showing WHERE, as a colored overlay).

YOUR PLAN: TWO LAYERS THAT WORK TOGETHER
----------------------------------------
Layer A, the change MAP (classical, no ML, cannot fail): compute where
pixels differ between the two images. This gives the visual evidence.
Layer B, the change WORDS (a model): describe the change in language.

TASKS, IN ORDER
---------------
TASK 1 (MINIMUM, do first, ~2 hrs): the classical change map.
  backend/tools/change/change_map.py
  a) Inputs: two aligned RGB arrays (Person 4's converter guarantees
     alignment; test meanwhile with pairs from the CDVQA or LEVIR-CD
     datasets, they are pre-aligned PNGs).
  b) Steps with OpenCV/numpy: convert to grayscale, blur slightly
     (cv2.GaussianBlur) to kill noise, absdiff, threshold (start with
     Otsu: cv2.threshold(..., cv2.THRESH_OTSU)), then clean the mask with
     morphological open/close. Result: binary mask of changed pixels.
  c) Also compute: % of scene changed, and rough location words by
     splitting the image 3x3 ("change concentrated in south-east").
  This alone answers "where did the change occur" and gives Person 5 a
  mask to draw. It also satisfies the optional "spatial change map" line
  in the problem statement, cheap win.

TASK 2 (MINIMUM, ~2-3 hrs): change description in words.
  Try in this order, stop at the first that works:
  OPTION 1: CDChat (https://github.com/techmn/cdchat), a chat model built
    exactly for bi-temporal satellite pairs. Check weights are downloadable
    and it loads on free Colab in 4-bit. Budget 1 hour to find out. If yes,
    wrap it like Person 2 wraps GeoChat.
  OPTION 2 (the honest fallback, still demoable): describe-then-compare.
    a) Run Person 2's GeoChat on image 1: "describe land cover and objects"
    b) Same on image 2
    c) Feed both descriptions + the Task 1 stats (% changed, where) to the
       local Ollama LLM (Person 1 has it running, qwen2.5:3b, free):
       "Given description A (date 1), description B (date 2), and the fact
        that X% of pixels changed mostly in the south-east, answer the
        user's question about what changed. Use only these facts."
    This composes three tools, which honestly SHOWS OFF the agentic angle.
  Tell the group which option you landed on.

TASK 3 (MINIMUM): wrap as our Tool.
  backend/tools/change/change_tool.py -> class ChangeTool(Tool)
  - copy the pattern in backend/tools/mocks.py, subclass from base.py
  - input_types = ["bitemporal_pair"], run(images=[t1, t2], query, **params)
  - ToolResult:
      text       = the change description / answer
      spatial    = {"type": "mask", "data": <binary mask array or PNG path>}
      confidence = from % agreement between Layer A and Layer B if you can,
                   else fixed 0.6 with "confidence_source": "fixed" in metadata
      metadata   = {"model": "cdchat" or "geochat+diff+ollama", "params": ...}
